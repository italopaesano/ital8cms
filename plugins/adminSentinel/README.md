# adminSentinel

> English translation pending. Authoritative version: [`README.it.md`](./README.it.md).

Admin GUI for the [`sentinel`](../sentinel/README.md) request filter — the
**🔭 Sentinel** panel section.

It turns a write-only log into something an administrator can act on: traffic
composition by family, rule status with the promotion traffic light
(*authenticated users hit*), HTTP fingerprints, suspected scanners derived from
outcome observation, and a recent-events table.
